# GUNBOND · 试玩版发布页

**试玩页（推荐）**：https://wangdingwen163.github.io/gunbond-trial/


2D 俯视角射击 + 枪械融合 Roguelite。逐层推进，捡枪、融合、越滚越强。

> 本仓库只存放**可执行试玩包**，不含源码。源码在主仓库，不公开。

## 下载

前往 [Releases](../../releases/latest) 页面下载最新的 `GUNBOND_Trial_v*.zip`。

解开压缩包后双击 `GUNBOND.exe` 即可运行，**免安装**。

## 系统要求

| 项 | 最低 |
|---|---|
| 系统 | Windows 10 64 位 |
| 显卡 | 支持 DirectX 11 |
| 内存 | 4 GB |
| 硬盘 | 300 MB（含存档与日志） |

## 包里有什么

```
GUNBOND.exe                主程序
GUNBOND_Data\              资源与托管程序集
UnityPlayer.dll            引擎运行时
UnityCrashHandler64.exe    崩溃上报
如何试玩.txt                操作说明与系统介绍（建议先读）
版本.txt                    构建版本与日期
重置存档.bat                清空进度、恢复初始状态
EULA.md                    最终用户许可协议
PRIVACY.md                 隐私政策
THIRD_PARTY_LICENSES.md    第三方组件许可
```

存档位置：`%USERPROFILE%\AppData\LocalLow\王鼎文\GUNBOND\`
